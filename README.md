# 霓虹涂界 Neon Turf

一款原创的浏览器 3D 涂色占地对抗游戏。玩家使用不同武器喷涂战场、争夺颜色覆盖率，并与 AI 队伍展开实时对抗。

项目基于 **Vite + TypeScript + Three.js** 开发，支持桌面浏览器与移动端横屏操作。

> 本项目为原创游戏原型，角色、地图、武器、UI 与游戏资产均为原创设计。

## 游戏特色

- 实时 3D 涂色占地与团队对抗
- 桌面端和移动端横屏适配
- 本地玩家对 AI 的 4v4 对战
- 8 名 AI 的上帝视角自动对决
- 空白广域场 10v10 大规模战斗
- 三张地图统一使用 72×72 大型战场尺寸
- 地面、墙面、平台、建筑、箱体与主要场景物件均支持局部泼溅喷涂
- 不同武器拥有独立射速、伤害、弹道和泼溅轮廓
- 己方墨水潜入、贴墙或贴面移动、加速、补充墨水与脱战回血
- 水气球副武器、滚筒接触伤害和人物身体沾墨
- 服装、发型与武器自由搭配
- 纯 SVG 局内 HUD 和移动操作图标
- 可选固定摇杆或浮动摇杆
- 无限墨水与无限血量娱乐模式

## 地图与模式

| 地图 | 规模 | 特点 |
| --- | --- | --- |
| 云顶集市 | 4v4 | 72×72 白色模块方块、屋顶露台、坡道、高层平台与空中连廊 |
| 潮汐铸造厂 | 4v4 | 72×72 白色模块方块、运河、厂房、桥梁与双层管线 |
| 空白广域场 | 10v10 | 72×72 无障碍超大平地，适合大规模 AI 对抗与性能测试 |
| 自定义战场 | 2v2～20v20 | 自选尺寸、白色方块布局、2～6 队和自定义规则 |

在主页可以选择：

- **开始对战**：控制青蓝队玩家角色，其余位置由 AI 接管。
- **AI 观战**：所有角色由 AI 控制，相机自动跟踪战场整体范围。
- **自定义战场**：在主页选择后进入编辑器，可选尺寸、每队人数、队伍数量、方块布局和战斗规则。

## 武器系统

游戏目前包含 8 种主武器：

| 武器 | 定位 |
| --- | --- |
| 脉冲喷笔 | 均衡连射 |
| 霓虹滚筒 | 近战铺色与接触伤害 |
| 涂浪桶 | 抛物线范围泼溅 |
| 色爆胶囊 | 大范围爆裂涂色 |
| 蓄能水枪 | 高伤害远程射击 |
| 散彩双枪 | 近距离高速爆发 |
| 疾风涂刷 | 高机动贴地连续铺色 |
| 喷射护伞 | 扇形范围压制 |

### 水气球副武器

- 消耗 50 点墨水投掷。
- 使用抛物线弹道。
- 落地或命中后产生大范围涂色、衰减伤害与击退。
- 伤害范围与实际颜色溅射范围一致。

## 墨水与战斗规则

- 主武器射击会消耗墨水。
- 玩家只能潜入己方颜色的墨水。
- 己方墨水可以出现在地面、平台顶面、斜坡、墙面或其他已命中的可涂表面。
- 潜墨期间移动速度提高，并快速补充墨水；在己方表面墨斑上可沿表面移动。
- 只有潜墨状态可以回复墨水。
- 受到伤害并脱战 3 秒后，潜入己方墨水可获得 5 倍回血速度。
- 敌方墨水会对站在其中的角色造成持续伤害。
- 弹丸、水气球爆炸、滚筒接触和敌方墨水都会在人物身上留下对应颜色的临时墨渍。
- 最终以双方颜色覆盖率决定胜负。

## 操作方式

### 桌面端

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` |
| 跳跃 | `Space` |
| 调整视角 / 瞄准 | 鼠标拖动 |
| 喷涂 | 鼠标左键 |
| 仅拖动视角 | 鼠标右键 |
| 潜入己方墨水 | `Shift` |
| 投掷水气球 | `Q` |
| 暂停 | `Esc` |

人物朝向始终跟随镜头方向，移动按键只负责位移，不会单独改变人物朝向。

### 移动端

- 左侧摇杆控制移动。
- 右侧按钮控制喷涂、跳跃、潜墨和水气球。
- 按住喷涂、潜墨、跳跃或水气球按钮并拖动，可以在保持操作的同时调整视角。
- 设置中可以切换：
  - **固定摇杆**：摇杆常驻左下角。
  - **浮动摇杆**：触摸左侧战场时在触点生成，抬手后隐藏。

## 角色与自由穿搭

装备工坊支持独立选择：

1. 主武器
2. 服装
3. 发型

服装和发型互不绑定，可以任意交叉搭配并保存到本地。

当前包含：

- 8 套服装
- 12 种发型
- 多种上衣、下装、鞋和装饰组合

发型包括短发、波波头、马尾、双马尾、长发、丸子头、刺发、编发、侧马尾、狼尾发、姬发式和卷发。局内发色自动跟随所属队伍的墨水颜色。

## AI 行为

AI 会根据战局在不同目标之间切换：

- 主动寻找未涂色区域并扩大己方覆盖率
- 敌人进入合适距离后交战
- 弹药不足或生命较低时撤退
- 在己方墨水中潜墨补充弹药和快速转移
- 识别坡道、平台、高低差与障碍物
- 主动跳跃越过低矮障碍或登上可达平台
- 卡住时重新规划转向和跳跃

## 自定义模式

自定义战场编辑器支持：

- 地图尺寸：48×48、60×60、72×72、84×84、96×96。
- 每队人数：2～20 人，可组成 2v2 到 20v20。
- 队伍数量：2、3、4、5 或 6 队。
- 队伍颜色：青蓝、橙光、酸柠、紫电、莓红、金黄。
- 方块类型：低台、高台、塔块；点击 12×12 网格即可摆放或删除。
- 比赛时长：60～300 秒。
- 可配置规则：跳跃、潜墨、特殊武器、复活、伤害和占地胜负。

自定义配置会保存到浏览器本地存储，重新进入时可以继续编辑。

## 设置

游戏设置会保存在浏览器本地存储中，包括：

- AI 难度
- 音乐与音效音量
- 镜头灵敏度
- 画面质量
- 固定 / 浮动移动摇杆
- 无限墨水
- 无限血量

无限资源选项只影响本地玩家，不会改变 AI 的资源规则。

## 技术栈

- [Three.js](https://threejs.org/) — 3D 场景与 WebGL 渲染
- [TypeScript](https://www.typescriptlang.org/) — 游戏逻辑与类型系统
- [Vite](https://vite.dev/) — 开发服务器与生产构建
- [Playwright](https://playwright.dev/) — 桌面端、移动端与交互自动化回归

## 本地运行

### 环境要求

推荐使用：

- Node.js 22 或更高版本
- npm
- 支持 WebGL 的现代浏览器

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

然后访问终端中显示的本地地址。

### 生产构建

```bash
npm run build
```

构建产物会输出到 `dist/`。

### 预览生产构建

```bash
npm run preview
```

## 自动化验证

项目包含针对以下功能的 Playwright 回归脚本：

- 桌面端、移动端和观战模式
- 地图选择与 4v4 / 10v10 人数
- 鼠标、触屏、按钮拖动与浮动摇杆
- 8 种武器
- 水气球副武器与多方向表面溅射
- 地面、斜坡、墙面和平台表面潜墨移动
- 潜墨、补充墨水和脱战回血
- 无限墨水与无限血量
- 服装和发型自由搭配及本地保存
- AI 涂地、跳跃、碰撞与长时间对战
- 多视口 UI 布局与纯 SVG HUD

## 浏览器数据

玩家设置、地图、武器、服装、发型和累计数据保存在浏览器 `localStorage` 中。清除站点数据后会恢复默认设置。
